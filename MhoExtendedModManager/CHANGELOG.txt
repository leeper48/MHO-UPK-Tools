MHO Extended Mod Manager: what's new
====================================

0.60.457
- FreeCam Options: Permanent Wall Fade (Disables F11 Toggle) is on two lines, so the Options card no longer cuts it off.
- What's New and the manual: Borrow Power's part boxes and Its Triggered Powers' Look Too (walkthrough and screenshot), the new FreeCam Options screenshot.

0.60.456
- FreeCam Options: the start-screen crash, really fixed this time. 0.60.453's fix had the wrong cause. Freecam's mouse-camera keys (middle mouse button, Tilde, F5, F6, F7 and F10) change key bindings when pressed, and a press while the start movie plays crashed the game: the change was reported to a part of the game that isn't there yet. Those changes are no longer reported (the keys work as before).

0.60.455
- Powers tab, Borrow Power: Whole Power has Animations, Effects and Sounds, and Props (Weapons and Vehicles) boxes. Untick one and the power keeps its own of that part: another power's effects with this power's own animation, or without the other hero's weapons.
- Powers tab, Borrow Power: Its Triggered Powers' Look Too: what this power sets off (Sorcerous Eruption's area) takes the look of what the other power sets off (Venom's spikes from the ground). Shown when both powers set off one.
- Make Unique (and Save): a costume model that one of the hero's power packages also carries (Cable's Future Bomb holds every Cable costume) gets a path of its own, as other characters' copies do: the power package can load first and show the game's model instead (a Bishop costume flipped back to Cable). When the mod ships that power package itself, the mod's model is put into it instead, so both show the mod's look.
- Model tab: a hero, team-up or NPC onto a pet now asks Whole Character or Fit, as a pet onto a pet does. Whole Character keeps the character's own skeleton and its idle, run and fidgets, at full size.

0.60.453
- FreeCam Options: Locked Behind Mode has Keep Current In-Game Zoom and a Zoom slider, as on Snap Behind: untick it to have Locked Behind start at the zoom shown.
- FreeCam Options: Default MHO's Game's Zoom is now Keep Current In-Game Zoom, and works as on Snap Behind: the zoom is left exactly as it is (before, the extra wheel steps were taken off).
- FreeCam Options: Permanent Wall Fade (Disables F11 Toggle) (Options): with Freecam 1.2, interior walls fade as in the base game instead of always visible; F11 no longer switches them.
- FreeCam Options: Lock Tilt on Locked Behind Mode keeps the camera at its Start Tilt (the stick and mouse camera don't tilt it).
- FreeCam Options: fixed a game crash on the start screen (about every third launch) with a gamepad action on Back: while starting, the game removes that button's bindings and reported ours to a part of the game that isn't there yet. FreeCam Options's gamepad lines are now left alone (they also no longer disappear from Back during a session).
- FreeCam Options: Remember Camera's saved camera (kept in two of the game's own HUD settings) goes back to the game's values whenever FreeCam Options isn't in the game (Remove, the Mods tab's Apply, and at start).
- FreeCam Options: Keep Current Zoom is called Keep Current In-Game Zoom on every card.

0.60.450
- Turning a mod on or off no longer makes the mod list jump: it keeps its scroll position.

0.60.449
- FreeCam Options: the Behind mode is now called Locked Behind, Isometric is called Default MHO, and Camera Mode is called Cycle Camera Mode.
- FreeCam Options: Locked Behind and Default MHO get a key and gamepad button each, to switch straight to that mode.
- FreeCam Options: Long Press Time (200 to 3,000 ms) for gamepad long presses, and a Short Then Long press (a tap, then press again and hold).
- FreeCam Options: Snap Behind is now Snap Behind / Free Orbit: it switches to Free Orbit from any mode (in Locked Behind or Default MHO it had no lasting effect). Selfie switches to Free Orbit too.
- FreeCam Options: a Default MHO Mode card: the game's tilt or your own, a height and the game's zoom or your own (the defaults are the base game's camera). The tab is laid out across the width (Controls, Options and View Distance on top, the camera cards under them), and each card's explanation shows on hovering the ⓘ beside its title.
- FreeCam Options: Remember Camera on Launch (on at first): the game starts, and changes zones, with the camera mode, zoom and angle you last had.

0.60.446
- F5 refreshes the Mods tab (the same as Settings → Refresh).

0.60.445
- FreeCam Options: Hide Level Numbers under Overhead Labels (the level number and its badge by characters' names).
- FreeCam Options: a View Distance card with the server's own chat command for a larger view (!aoi volume 5000), to type in the game's chat.

0.60.443
- Model tab → Materials: Edit in Image Editor (and the large view's Edit button) works on maps the app made too: an MHO spec map from your color tags, a generated normal or spec map, a glow map. Your first save in the editor becomes the material's own file; Back to Automatic goes back to the made one.

0.60.442
- Fix: the spec map viewer's channel buttons crashed on a click (0.60.441).
- Fix: the viewer lost a map's colors where its alpha is 0 (on a spec map: skin and cloth, whose reflectivity is 0), so the skin mask showed black; and the channel buttons were hidden under the picture.

0.60.441
- Model tab → Materials: viewing a spec map (MHO Spec, Spec (Packed)) shows its colors without its alpha first, which is a channel of the map (reflectivity), not transparency; parts with none (skin, cloth) used to show as see-through. Buttons show RGB, RGBA, or one channel by name as gray (R: Shine, G: Power, B: Skin Mask, A: Reflectivity …).

0.60.440
- Model tab → Materials: double-clicking the Spec row of a material that uses an MHO spec map (one made from your color tags, say) shows that map instead of nothing.

0.60.439
- Model tab → Materials: Tag Colors works on a costume package's own textures (no source picked): the package's packed spec texture is made from your tags in its own layout; untagged parts keep what they have. The tags are kept with the mod.

0.60.438
- Model tab → Materials: right-click a row for Generate Spec Map (the shine made from the color map: Soft, Strong, Dark Is Shiny, Detail, Flat) and Generate Spec Color Map (from the color map, half tint, white, or one color), and Tag Colors / From Channels when the row allows them. They also work on a package's own textures: the packed spec texture's shine channel is replaced and its other channels kept.

0.60.437
- Fix: Save dropped changes made to a package with dodge ghosts since its ghosts were first made (a material copied on the Model tab, Model builds, borrowed looks): the ghosts were rebuilt from the copy kept back then. They are now built onto the package as it is.

0.60.436
- Model tab → Materials → Copy Setup From a Costume: the list also has the materials of the costume's props (the other models in its package, marked Prop), such as Captain America's shield.

0.60.435
- Borrow Power: a power with no animation of its own that is still cast (Invisible Woman's Seeker Orbs, Psylocke's Katana Typhoon) can borrow a look, and plays the other power's animation. Passive powers and talents can't. Confirmed in game: Seeker Orbs with Jean Grey's Telekinetic Throw.
- Fix: borrowing one of Jean Grey's powers took the animation from her Phoenix set (the flying version) instead of her normal one.

0.60.434
- Animations tab: a form's animations can be changed (Jean Grey's Phoenix and Dark Phoenix sets: rows marked Form). The change goes into the costume's own copy of that form's set, with the new animation fitted to the set's bones; Back to the Original undoes it. Confirmed in game with Jean's own and Storm's idles in her Phoenix form.
- Fix: an animation fitted to another set's bones now has its data written in that set's order (it played distorted in game before).

0.60.433
- Fix: some powers showed "No Animation of Its Own" (and couldn't take a borrowed look) when another hero's power shares their class: Jean Grey's Crushing Telekinesis and Telekinetic Throw (Cyclops's ultimate calls her in with the same classes), Expel Phoenix Force, and powers of Beast, Black Bolt, Black Widow, Carnage, Deadpool, Emma Frost, Iron Fist, Nova, Rogue, Squirrel Girl and Star-Lord. A power's class now goes to its own hero's powers first.

0.60.432
- Fix: Dodge Ghosts → Make Them From This Model used another costume's stock body when the mod also had that costume's package (a borrowed power brings them in). It now uses the model the 3D view shows.

0.60.431
- Fix: borrowing a power whose parts come from game packages the target power doesn't load (Emma Frost's Running in Heels and the other sprints on a flight or run of another kind) crashed the game, first when it loaded and then when the power was used. The game loads only the packages each power lists; a borrowed part now carries the settings it needs from those packages itself, and a part whose kind is only defined there (a sprint's foot dust) is left out. Borrowed rides (a bike on another hero's travel power or Sky-Cycle) follow the same rule: they no longer carry a copy of the game's shared ride class, which could crash when that hero was nearby. Re-save a mod with such a borrow (right-click → Resave) to rebuild it.

0.60.426
- New FreeCam Options tab: options on top of Marvel Heroes FreeCam (M.H.F.C.) by Michael (MichaelMerc on Nexus); needs his mod installed with its Full option, and links to its Nexus page when it's missing.
- Camera Mode key and button: Free Orbit, Behind (follows the way your hero faces) and Isometric (the game's own view).
- Snap Behind and Selfie: the camera jumps behind your hero or in front facing them, each with its own tilt, height and zoom (or keeps the current zoom).
- Keys and gamepad buttons of your choice; actions can share a button with a short, long (1 second) or double press.
- Invert Y (off by default), more mouse-wheel zoom past the game's closest and farthest steps, tilt limits and orbit speed.
- Overhead Labels: Hide Names, Hide Titles and Hide Guild Names take that text off the labels over characters.
- Apply to Game changes only the game's own MarvelGame.upk and MarvelHUD_SF.upk and your key settings; Remove puts them back exactly as they were.
- Ground decals: a power's marks on the ground (Luke Cage's "CAGE" from Cage Was Here, scorch marks, cracks) are on the Powers tab's Parts list as Decal. The ✎ beside one sets its color (its glow and fade keep their brightness) and, per image, opens it in your image editor (each save there is taken in and shows in the 3D view at once), replaces it with your own image, exports it, or puts the game's back. Untick it to switch it off. Save writes them into the power's package; the images travel with the mod.
- Power Colors also tint a power's decal glow and its fade.
- The 3D view draws ground decals as the game blends them (a darkening layer and a glow in the decal's color), with your unsaved changes.
- Model tab: effect models are named by the power that uses them ("Cage Was Here · Chainfist Wrist"), grouped by power, and the filter finds them by power name.
- Install Mod (and drag and drop) take a game package (.upk) on its own, or an archive or folder of them without a manifest, and make it a mod. Only the game's own package names are taken.
- Fix: a Voice Shift was lost when the mod also borrowed a power for the same hero (Save rebuilt the hero's package without it; the voice played unshifted in game). Save keeps it now; saving such a mod once puts it back.
- Fix: power previews showed characters a power only checks for (Luke Cage's Cage Was Here showed Misty Knight, whom only a talent brings).
- 3D views: strong reflections no longer turn shiny armor white (blended, not added on).

0.60.407
- Move to a Pet: a costume's Costume menu has Pet under Team-Up. Pick one of the game's vanity pets and it takes the costume's model with its idle, run and fidgets, the costume icon as the pet's item icon and the hero portrait as its store image. Full Size keeps the hero's size (most pets are shrunk), and Name in Game sets the pet's name. The costume and the pet can both be on.
- Move to Another Pet: right-click a pet mod to put that pet on another of the game's pets, with its own skeleton and animations (a four-legged pet stays four-legged on a two-legged one).
- Team-ups can be moved to pets too, including Thor's team-ups, whose animations live in a shared package.
- Pet mods show the pet's icon on their card in the mod list.
- Model tab: a Pets tab in Source and Target. Every pet with a model of its own is listed; a model fits best on the pets with the heroes' skeleton (Iron Buddies, Ultrons, sentinels, Vision, Spider-Ham). With a pet as the source and another pet as the target, picking the target asks Whole Pet (the source pet as it is, with its own skeleton and animations) or Fit, and the preview shows what that builds.
- 3D views: with Chain off, the arrows beside the frame slider step through the animation list.
- Fix: a mod's textures that the game streams no longer show flat colors on a pet or team-up (Luna Snow as Baby Groot drew plain lilac and grey).
- Fix: a move from a team-up copy took the stock model left in its package instead of the mod's (Odin moved to a pet came out as Old Man Thor).
- Fix: some pets borrow another pet's picture in the game's data (Baby Groot names Old Lace's store image); the Pet window shows each pet's own, and a move can't change another pet's picture.

0.60.388
- The Move window has a Name in Game row: the name the costume or team-up will show, ready to edit. On a team-up it suggests the costume's name made plain ("ENHANCED Odin Costume" becomes "Odin"; the team-up unlock window shows color tags as raw text). It says whether anything else in the game shows the same name, since a new name changes theirs too. Unticked, the game's name stays.

0.60.387
- Moving a costume onto a team-up is easier to find: the Costume menu has Team-Up under Another Hero, which opens the picker on the team-ups (Angel, Jessica Jones …), and the Team-Ups tile now comes first in the hero picker. The model, voice and icons move as onto a hero's costume; the team-up window shows only team-ups.

0.60.386
- Borrow Power is out: in the Editor's Powers tab, give a power another hero's power look (its animation, effects, sounds and projectile, with the weapons, vehicles, thrown characters, summons and areas that come with it). Only the look changes, so it works on any server. Reset Power takes it back to the game's look. The manual has a walkthrough (Give a Power Another Hero's Look).

0.60.385
- Borrow Power (preview feature, hidden): the Powers tab's Borrowed Look is now Borrow Power, with icon buttons: Borrow Power (a lightning bolt with an arrow) and Reset Power (a circular arrow), which takes the power back to the game's look (was Game's Look).

0.60.384
- Borrowed powers that throw a character: Colossus's Fastball Special (Wolverine flying, clawing) and other animated projectiles can now be borrowed: the thrown model and its flight animation come along.

0.60.383
- Borrowed powers with morphing models: the Thing's Hammer Time, Stretch! (Mr. Fantastic as the mallet) and other powers whose models stretch or change shape can now be borrowed (their morph targets are copied along).

0.60.382
- A charge-up's look on a channel: its release animation now ends the channel's looping animation instead of being a separate animation part, which kept the charge from starting at all when you pressed (found with a controlled test against a borrow that worked).

0.60.381
- A charge-up's look on a channel: the charge animation is played by a copy of the channel's own looping animation (the same settings, the borrowed animations), so it starts when you press.

0.60.380
- A charge-up's look on a channel: its charge animation no longer loops on its own (a channel ends its loop when you let go), which kept it from starting at all.

0.60.379
- A charge-up's look on a channel: its looping animation keeps its own start and end, as a channel's does, so the hold starts and the charge plays while you hold.

0.60.378
- A charge-up's look on a channel: the charge now runs while the channel is held (from the start of its loop). Starting it with the power, it never came up on Punisher's Ol' Painless.

0.60.377
- Borrowed powers: a charge-and-release power's look (Human Torch's Extreme Combustion) on a power that isn't one now plays. Its charge runs from the power's start and its release comes at a channel's end (Punisher's Ol' Painless) or at an attack's hit. Before, the charge never played and the release came once at the start. Borrow a Power's Look also tells charge-up powers from channels ("Charge and Release") and says what will happen.

0.60.376
- Borrowed attacks: the other hero's weapons and props the borrow brings (Deadpool's cannon, Punisher's M60) get paths of their own, as borrowed vehicles already did. With the stock paths, once that other hero had been loaded in the game, his own copy could stand in for the borrowed one, with his own animations.

0.60.375
- Borrow a Power's Look: Its Area's Look Too. When the other power's look comes partly from an area it puts down (Squirrel Girl's rain of squirrels in It's Raining Rodents), those effects play at the target as part of this power: from the hit, for the effect's own length (one that loops plays 4 s). Areas only an ultimate, talent or signature puts down aren't brought. It's a look, not a real area: it doesn't follow a moving target.

0.60.374
- Borrow a Power's Look: Its Summon's Look Too. When both powers summon a model (Hawkeye's Claymore Turret, Squirrel Girl's squirrels), what this power summons takes the other's model and animations: its spawn, idle, combat idle and attacks are matched by what they're for, and the places its effects come from are fitted to the new model's size. A summon that's only an invisible marker (Doctor Doom's Unthinkable orb, drawn with effects) isn't offered.

0.60.373
- Faster 3D views and steadier windows (performance changes contributed by pants on a tiger): characters animate about a quarter faster per frame, a 3D view on a tab you can't see stops drawing, fonts and brushes are shared instead of made on every paint, tables no longer flash while scrolling, and the Voice tab's Find waits until you stop typing. The pictures are exactly the same as before.

0.60.372
- Manual: walkthroughs for raising or lowering the body during an animation (Height strip and Gizmo) and for rebuilding a mod after an update (Resave), with new pictures for Apply Changes, moves to a costume of its own class and Not in This Voice.

0.60.371
- Voice → Use Another Voice keeps silent every situation the new voice has no line for (a team-up's voice has no death or level-up line, for example), as a move to another hero already did. Before, the hero's own lines played there, so two voices were heard. Those rows show as Not in This Voice.
- Model tab: Source Parts has a grip under it. Drag it down to make the list taller; double-click it to go back to the height of its rows. The height is remembered.
- Move to Another Costume lists the hero's costumes whose class is of another kind (Captain America's American Dream is its own class, not Cap's). They were missing from the costume list and left out of Another Hero, so a move had to go through another hero and back. They now move the way a move to another hero does: the target costume's own package with the mod's model put in.
- Power colors no longer recolor a face of the game's lighting cube map (it isn't an effect's color). Recolored, its six faces no longer matched, and Magneto's Magnetic Eruption crashed the game as soon as it was on the power bar.

0.60.369
- Borrowed powers: when the other hero's socket for an effect points another way than this hero's (most heroes' head socket points sideways, Emma Frost's and a dozen others' forward), the borrowed effects get the other hero's socket under its own name. Emma's Psychic Blast on Blade came out of the side of his head; it now fires forward. The hero's own powers keep his socket.

0.60.368
- Borrow a Power's Look warns when another mod you have on replaces one of the hero's costumes with an animation list of its own. In those costumes the borrowed animations aren't found, and the hero stands in his rest pose for that power (Black Bolt under the Havok conversion mods).

0.60.367
- Borrowed attacks: an animation with a hit marker is no longer fitted to this power's length. The game already times it to the hit, and the fit sped it up a second time (Deadpool's Real Armor Buster on Doctor Strange ran almost four times too fast, and his hands left the cannon).

0.60.365
- Saved and exported mods no longer carry the Dodge Ghosts' preview builds (Model\ghost_build). They could add tens of MB to a mod. The ghosts themselves are saved in the mod as before.
- Borrowed attacks: a channeled power's look on a single-shot power (Vision's Channeled Solar Beam on Cyclops' Optic Blast) now shows. Its parts timed on the channel's loop run at the attack's contact and end instead.
- Borrowed attacks: a weapon spawned for the power no longer disappears when the hero has weapon slots of the same name (Punisher's M60 on Nick Fury).
- Borrowed attacks: weapons the other hero puts away for the whole attack no longer come along (Deadpool's pistols in Real Armor Buster).

0.60.364
- Borrowed attacks: a prop that follows its wearer's animation by bones this hero lacks (Hawkeye's bow on Thor) is held in the hand instead. It didn't show at all before. The hand is the one the prop's own bones hang from.
- Borrowed attacks: a weapon the other hero's power hides for part of the attack (Hawkeye's arrow at the shot) comes along. Only travel powers leave out a weapon the hero puts away for the whole ride.

0.60.362
- Borrowed powers from Magik, Human Torch and Ghost Rider could fail with "couldn't be copied". Their always-held attachments have socket and effect lists the copier now reads.
- Borrowed attacks: an always-on effect attachment (Human Torch's body flames) comes along only when the power's effects come out of it. Weapons with a model (Magik's soul sword) still come.

0.60.361
- Make Unique no longer renames effect materials. A renamed material lost its shaders and drew as flat blue and grey squares, like the muzzle flash and smoke of Punisher's Full Auto borrowed by Blade. Materials keep their paths now, like streamed textures.
- Borrowed powers: a hero whose biggest model is a prop (Blade's motorcycle) is no longer read as having that prop's skeleton. The borrowed M60 stood between Blade's legs because the bike has no hands.
- Borrowed powers: a weapon on a bone the hero lacks goes on the hand the other hero's animations hold it in.

0.60.360
- Borrowed attacks: a weapon the other hero's power switches to now shows. A weapon slot the hero has nothing in is no longer hidden, because that hid the borrowed gun too. Blade borrowing Punisher's Full Auto held no gun: the power swaps Punisher's weapons in slots only he has. The other hero's weapon is now spawned while the power runs.

0.60.358
- Borrowed attacks: the hero's own extra bones (cloth, hair, ribbons, capes, extra knee bones) follow the hero's own power while the other hero's animation plays. Angela borrowing Cyclops' tumble locked into an A-pose: his animation moves 82 of her 176 bones.

0.60.357
- Borrowed attacks bring the other hero's held weapon again: Scarlet Witch borrowing Angela's sword combo swung no sword. Only travel powers leave out a held weapon that their effects don't come out of.

0.60.356
- Borrowed travel powers: sounds and effects that repeat with the travel loop keep the other hero's timing. Spider-Man's web shots fired every half second on Captain America, because Cap's own run loop, kept for other characters sharing his run power, set the timing. A borrowed travel power now keeps none of the hero's own parts, so characters sharing it get the borrowed look too.

0.60.355
- Borrowed travel powers: another hero's always-held weapon comes along only when the power's effects come out of it. Thor's hammer still comes with his flight; Kitty Pryde's sword no longer comes with her Air Walk.

0.60.354
- Borrowed travel powers: a ground ride on a hero who flies high (Cyclops' ride on Kitty Pryde) no longer dips under the floor when the loop starts. The game was still lifting the hero when the start ended. Unless you set a climb speed, the hero now climbs fast enough to be up by then.
- Borrowed travel powers: Green Goblin no longer leans back on another hero's ride. Cyclops' ride switches on his bike-tilt control, and Goblin has a control of that name for his glider. On heroes like Goblin, the other hero's control switches are left out.

0.60.353
- Borrowed travel powers: Cyclops rode two of Green Goblin's gliders. A rebuild started from a ride condition an earlier build had already changed, so the power kept its own glider too. Such a condition now starts from the game's original.
- Borrowed travel powers: on heroes without Goblin's mount bone (Captain America, Kitty Pryde) the glider sat at their feet's level while they stood above it. It's now raised by the height of Goblin's mount bone over his root in his flight (the root already rises with the borrowed animation).
- Borrowed travel powers: a vehicle the power shows gets paths of its own, as one shown by a ride condition already did. Once Green Goblin had been played, the borrowed glider used his own copy.

0.60.351
- Borrowed travel powers: a weapon the other hero puts away during the power isn't brought along. Hawkeye's bow and arrow stayed out on everyone riding his Sky-Cycle.
- Borrowed travel powers: Cyclops and Green Goblin sat about 16 units above the Sky-Cycle's seat. Hawkeye's ride animations include a mount-bone track for Kate Bishop's skeleton, which their models also have. A mount-bone track the other hero's own model doesn't use is left out now.
- Borrowed travel powers: the hero's own animated companions keep moving. Kitty Pryde's Lockheed hung still under Hawkeye's ride, because he has no animations by its names; his own flight animations now play under them too.

0.60.350
- Borrowed vehicles: Hawkeye's Sky-Cycle on Cyclops's ride couldn't be borrowed ("the .tfc couldn't find it"). The Sky-Cycle's group holds textures the game streams and finds by their path, so those keep it now; the bike's other parts still get paths of their own.
- Borrowing Green Goblin's flight onto a ride (Cyclops) stopped with "has no Components list": his flight's condition only plays animations and shows no vehicle, so it's skipped now.

0.60.349
- 3D view: a thrown weapon flies at its power's own speed from the game data. Thor's Hammer of Storms flies at 1,300 units a second; the view used 900 for everything, so the hammer came back late.
- 3D view: an attack whose animation is named like the end of a channeled power, but isn't one, plays like any other attack. Thor's Hammer of Storms only plays its …_end animation, at the game's speed (0.7 s), with its throw at the right moment. Whether a power is channeled now comes from its game data, not the animation's name.

0.60.348
- 3D view: an effect timed a set delay into a sped-up attack now comes as much earlier as the attack is faster, as in game. Thor's Spinning Strike arc waits 0.5 s in the attack's own time, but the attack plays 1.25× faster, so it comes 0.40 s in. A channeled power's delays (Lightning Storm) stay in real time, as the game has them.

0.60.347
- 3D view: attacks with a hit marker in their animation play at the game's speed too. The game speeds the animation up or slows it down so that its hit frame lands on the power's hit moment. Thor's Hammer Smash plays 2.24× faster, not the 1.75× the power's time alone gives, so the hammer now hits the ground as the impact appears. Checked against the game on four of Thor's attacks: all four play at the game's speed.

0.60.346
- 3D view: power effects that don't name when they start now start when the game starts them. A particle effect's default is the power's hit (contact) moment, not its start: Thor's Hammer Smash impact showed at once and now shows when the hammer lands. Effects at the hit moment are timed on the power's own clock (its animation time in the game data), as in game.
- 3D view: attack animations play at the game's speed. The game fits a power's animation to the power's time (Thor's Spinning Strike plays 1.25× faster, Leaping Smite's start 1.33×), and the 3D view now does the same, so the hit effects line up with the swing. Loops and travel powers play as before.
- New commands that change nothing: --proto-fields <prototype> lists a power's game data fields; --fx-placement takes a game package as well as a mod.

0.60.345
- 3D view: a power whose start, loop and landing aren't named alike (Thor's flight: movement_run_flying_start, movement_run_flying, movement_landing) now plays each part's own effects. The start used to play every effect, so the landing dust showed at takeoff.
- New command that changes nothing: --fx-placement <mod> <animation> lists where the 3D view places a power's effects, frame by frame, to compare with the game's.

0.60.344
- Borrowed effects' points on costumes: a costume package the borrow mod already includes (for the costume's own animation list) now always gets them, even when a costume mod also replaces it. Cyclops' Astonishing costume was in the Thor Fly mod without the point, so Thor's hammer glows didn't show on it. Resave the mod to rebuild it.

0.60.343
- Right-click a costume mod → Add Borrowed Power Sockets: for a costume the borrow leaves alone because a costume mod replaces it (Cyclops' 90's X-Men Brown Jacket under Thor's flight), this adds the points the borrowed effects sit on to that mod's own costume models, for the borrow mods in your library for the same hero. It asks first. Then Apply Changes.

0.60.342
- Borrowed effects on a point of the other hero's body now show on every costume. The point is added to each costume's own model too, so the mod includes the hero's costume packages (Cyclops: 11, mostly under half a MB each). A costume package that a costume mod in your library replaces is left out and named in the log, so the borrow never overrides your costume mods. A costume included in the borrow mod itself gets the point. Resave the mod to rebuild it.

0.60.341
- Test withdrawn: naming a bone instead of a missing point on the body doesn't work in the game (the effect doesn't appear at all), so borrowed effects go back to 0.60.339's way: the point is added to the hero's own model. Costumes with a model of their own, such as Cyclops' 90s X-Men, still don't show those effects. Resave the mod to rebuild it.
